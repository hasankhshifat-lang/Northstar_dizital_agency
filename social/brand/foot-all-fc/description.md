# Foot All FC: YouTube channel description

Paste into YouTube Studio → Customization → Basic info → Description (YouTube allows up to 1,000 characters; this is about 750).

---

The greatest football stories ever told, cut from paper.

Impossible comebacks, last-minute miracles, underdog titles and the players who changed the game, retold as hand-cut paper cartoons. Every goal is a paper patch slapped on the scoreboard, and every story is checked against the official match records.

New Shorts every week, plus longer deep dives into the matches fans still argue about.

⚽ Comebacks · Miracles · Rivalries · Legends

Subscribe and tell us in the comments which story we should cut out next.

Foot All FC is an independent fan channel. We aren't affiliated with or endorsed by any club, league or broadcaster. Club names are used only to tell true stories. No match footage is used. Narration is voiced with AI.
