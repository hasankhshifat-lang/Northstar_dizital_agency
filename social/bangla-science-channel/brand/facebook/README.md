# Scientific Bithi — Facebook page images

- `scientific-bithi-cover-1640x624.png`: cover photo. The title and characters sit inside the centre band (about x 265–1375) that Facebook's mobile app keeps when it crops the sides.
- `scientific-bithi-profile-1080.png`: profile picture. Bithi waving, framed to fit the round crop.
- `make_brand.py` + `shot.js` rebuild both from the episode character rigs (`python3 make_brand.py <scratchpad>`, then `node shot.js <scratchpad>/brand`).

Page name: **Scientific Bithi** (Bangla: সাইন্টিফিক বিথী). Tagline on the cover: "হাসতে হাসতে বিজ্ঞান শিখি".
