# Video scripts

One file per video: `<VIDEO_ID>.md` (or `<working-title>.md` before upload, renamed once the video has an ID).
The youtube-thumbnail-creator skill reads the full script from here before writing a thumbnail heading.

Before picking a topic or writing a script (YouTube or Facebook), read and follow
`docs/content/scriptwriting-rules.md`: topic score, research report, hook, structure and the final checklists.

Before animating, add a `## Storyboard` section (scene table) and follow
`docs/content/animation-direction-rules.md` (direction, scene inspection, learning database).
