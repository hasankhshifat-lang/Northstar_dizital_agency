# As Printed — channel art

- `banner.jpg` / `banner.png` — YouTube banner, 2560×1440. Title and tagline sit inside the 1546×423 area YouTube shows on every device.
- `profile.png` — profile picture, 800×800 (YouTube crops it to a circle; the loupe ring is the circle. A single "A", not "AP", so it never reads as the Associated Press mark).

Made from the same public-domain archive material as the first film (Library of Congress: Chronicling America
newspapers; Bain News Service glass negatives LC-B2- 2485-4, 2391-30, 2485-2), with IBM Plex Serif / Mono / Sans (OFL)
and the Archive Light Table colours (table #F7F9FB, ink #15171A, signal orange #FF5A1F).

Rebuild: `node src/shoot.mjs` (edits go in `src/art.html`).
