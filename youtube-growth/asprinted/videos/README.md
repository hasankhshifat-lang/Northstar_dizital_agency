# Per-video records

`videos/<VIDEO_ID>/` holds `production-plan.md` (scene-by-scene plan, or a link to the episode folder),
`thumbnail-record.md` (concepts, choice, scores, CTR over time) and `performance.md` (checkpoint notes and the
diagnostic report). The script stays in `social/scripts/<VIDEO_ID>.md`; raw metrics in `../analytics/snapshots.jsonl`.
